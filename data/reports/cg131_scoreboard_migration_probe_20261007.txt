생성: 2026-10-07 05:0x KST (모델 엔지니어 자율, 읽기 전용 증거 — 스코어보드 자체는 미변경)

[왜 이 증명이 필요한가]
북극성 헤드라인은 "로버스트 0.5519(TR_rank_h5) vs 등록 기준선 0.5406 → Δ0.0113 · 19사이클 무개선"이다.
그런데 (a) 비교 패널 `panel_420_asofpatch.npz` 는 as-of 수리(2026-10-02 CG63) **이전 빌드**이고,
(b) 헤드라인 arm `TR_rank_h5` 는 횡단면 rank 변환이라 배포 추론 경로에서 재현 불가다.
= 헤드라인 수치가 '누수 패널 + 비배포 arm' 위에 서 있다. 이관은 스코어보드 프로토콜 변경이라
리뷰보드 승인 대상이므로, 승인 즉시 실행할 수 있도록 수치·사양을 여기 고정한다.

[실측 3 — 청정 패널에서 '배포 가능' 최고 arm 과의 같은-런 짝]
  CG87 같은 런(panel_prod200·5폴드×5시드):
    CO_core30_h5   0.5305±0.0199  Δ+0.0003  (게이트 ON 대조군, 배포 가능)
    CO_smooth_d1_h5 0.5355±0.0143 Δ+0.0053  (게이트 ON+라벨스무딩+depth1, rank 없음 = 추론계약 무변경)
  → 청정 패널에서 배포 가능한 최고 arm 도 사전문턱 +0.02 미달 = 노이즈.

[실측 4 — 헤드라인 arm 은 배포 불가]
  TR_rank_h5 = 횡단면 rank 변환. 추론은 종목 단위 스트리밍:
  services/xgboost-ml/app/inference/predictor.py:137  def predict(self, stock_code, date=None)
    → :143 features = self.feature_pipeline.build_features(stock_code, date)
    → :146 [features.get(f, 0.0) for f in feature_names]
  날짜별 횡단면 rank 는 '그날 다른 종목 값'이 필요한데 이 경로엔 없다 → 재현 불가(스킬 기록과 일치).
  또 rank 축 자체는 이미 여러 번 종결(150종목 전이 −0.0109 CG5 · 구간짝 −0.0057 CG14 · +0.0010 CG69).

[결론]
  이관(누수 패널 폐기 + 비배포 arm 제외 + 기준선 재등록)을 해도 **판정은 뒤집히지 않는다**:
  청정 패널 배포가능 최고 Δ = +0.0053(노이즈) → 19사이클 '무개선' 결론 유지.
  즉 이관은 성능 판정 변경이 아니라 **측정 정합성 수리**다(위험이 낮고, 지금 헤드라인이
  누수 패널·비배포 arm 이라는 사실만 제거한다). "새 레버 필요" 승격 요청은 그대로 유지된다.
