# 희박 이벤트 피처 재정의 (5일 카운트 → 레벨·추세·묶음)

대상: `event_*_5d` 처럼 드물게 발생하는 사건을 **5일 창 단독**으로 잡은 피처가 nnz<5% 로 DEAD_SPARSE 인 경우.
임계를 낮추거나 0을 채우는 게 아니라 **정의를 바꿔** 정보를 늘린다. 실측: 신규 8개 중 7개 ALIVE.

## 원칙

- **이미 창합인 컬럼을 다시 창합하지 마라.** `event_*_5d` 는 5일치 합이므로 20일 구간을 “합”하면 이중계산이다.
  창 안의 값을 **평균·비율·이진화**해서 쓴다.
- **as-of 는 당일 행을 제외**한다(직전 N행). 당일 이벤트를 피처로 쓰면 라벨 누설이다.
- **창이 모자라면 null** — 0으로 메우면 “발생 안 함”과 “관측 없음”이 섞인다.

## 검증된 8개 정의

| 피처 | 정의 (직전 N행, 당일 제외) | 실측 nnz |
|---|---|---|
| `event_any_60d` | 60행 중 총 카운트 > 0 → 1 | 95.6% |
| `disclosure_level_20d` | `disclosure_count_5d` 의 20행 평균 | 72.4% |
| `event_level_20d` | 전체 이벤트 5d 카운트의 20행 평균 | 71.7% |
| `governance_level_20d` | 지분변동+임원변경 20행 평균 | 60.0% |
| `event_trend_5v20` | (직전 5행 평균) / (직전 20행 평균 + 1e-9) | 53.9% |
| `business_level_20d` | 수주+신제품+제휴+실적 20행 평균 | 47.1% |
| `funding_level_20d` | 유상증자+CB/BW+M&A+자사주 20행 평균 | 30.3% |
| `risk_level_20d` | 소송+재해+규제+리콜 20행 평균 | 4.6% (희박 유지) |

묶음(자금조달/지배구조/영업/리스크)이 개별 17타입보다 잘 살아난다 — 개별 타입은 원래 희소하고,
묶으면 “이 종목에 요즘이벤트 압력이 있는가”라는 질문이 되어 분산이 생긴다.

## 절차

1. 원천 테이블 컬럼·기간·커버리지를 **패널 코드×기간**으로 먼저 확인(테이블 전체 행수는 착시).
2. 신규 테이블(예: `event_rolling_features`)에 종목·거래일 PK 멱등 upsert. `--dry-run` 로 행수·컬럼별 nnz 미리보기.
3. 패널에 **새 컬럼만 append**(213→221). `--out == --panel` 이면 exit 2, 기존 컬럼 바이트 동일 assert,
   행수·dates·codes·price 동일 assert. 원본 패널은 절대 덮지 않는다.
4. 생존 재판정 → 신규 8개 중 nnz≥5% 개수가 기대치(예: 5개 이상)를 넘는지 확인.
5. 그 다음에야 AUC — 단, **선별 문턱을 먼저 확인**한다(경계 |IC| 와 피처 순위). 경계 밖이면 WF 를 돌려도
   결과는 비트 동일하다.

## 함정

- 집계 통계에서 NaN 을 `!= 0` 으로 세면 nnz 가 부풀려진다(표시 버그). 마스크(`np.isfinite`)로 세고,
  생존 리포트 수치와 대조해 일치하는지 확인하라.
- 이벤트 정의를 바꿀 때 원천에 없는 타입(특허·리콜 등)은 만들어도 0 이다 — 정의 변경이 아니라 **수집기** 문제다.
