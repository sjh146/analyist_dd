# 실비용 감사 — 수수료·세금·체결 슬리피지 (기대값의 1차 항)

전략 기대값을 논하기 전에 **왕복 실비용을 원장에서 실측**한다. 가정치(예: 0.21%)를 그대로 쓰면
그 위에 세운 손익비·문턱 결정이 전부 무효가 된다. 세 단계로 하고, 각 단계의 산출물을 보고에 남긴다.

## 0. 먼저 알람: fees 컬럼이 정말 채워지고 있나

```sql
select count(*) filter (where exit_ts is not null) as closed,
       count(*) filter (where exit_ts is not null and coalesce(fees,0) > 0) as with_fees
from trades where date(ts) >= date('now','-30 day');
```

`with_fees = 0` 이면 **모든 기대값이 gross**다. 원인은 대개 계상 잡의 조용한 skip 이다
(브리지 미연결 → "수수료 계상 건너뜀", 파싱 실패 → "비용 플래그(check)"). 잡 로그 tail 을 읽어
"오늘도 건너뜀"을 확인하고, skip 사유를 보고에 그대로 쓴다. 잡이 성공한 날이 한 번도 없으면
그 수수료 백필은 존재하지 않는 기능으로 취급한다.

## 1. 요율 모델로 최소한의 net 을 만든다 (브로커 값이 못 쓸 때)

브로커의 종목별 실현손익은 **천원 단위로 절단**되어 소액 거래에서 전부 0 으로 온다(2,233원 → `2`).
그 값을 비용 도출에 쓰면 모든 행이 "음수 비용" 또는 "과대 비용"으로 찍힌다 — 데이터가 나쁜 게 아니라
**단위 불일치**다. 이때는 요율로 계상하고 **출처를 남긴다** (`fees_source="rate"`).

- 매수 수수료 `0.015%` + 매도 수수료 `0.015%` + 매도 거래세 `0.15%` → 왕복 약 **0.18%**
  (요율은 계좌·이벤트로 달라지므로 쓰는 값을 보고에 명시하고, 정확한 값은 체결내역 export 로 대체한다.)
- `fees = round(buy_amt·c + sell_amt·c + sell_amt·tax)`, `net = gross - fees`.
- **미체결 취소 행에는 비용을 붙이지 마라.** `exit_reason` 에 `cancel`/`unfilled` 이 있거나
  `exit_price == entry_price` 인 행을 건너뛰지 않으면 취소 주문에 수수료가 붙는다(실측: 0원 거래에 46원).
- gross 는 반드시 별도 컬럼/출력으로 보존한다. `pnl` 만 덮어쓰면 나중에 gross/net 을 분리할 수 없다.

## 2. 체결 슬리피지 — 트리거가 ≠ 체결가

청산이 시장가면 저널의 `exit_price`(트리거)와 브로커 평균매도가가 벌어진다. 트리거 가격을
체결가로 읽으면 성과가 낙관 편향된다. 저널의 계획가(`algo_json.reference_price` 또는 사이클 호가)와
실제 체결가를 짝지어 분포를 낸다.

```python
slip = (fill - ref) / ref * 100      # 매도는 음수가 불리
```

보고 형식: **건수 · 평균 · 중위 · 최악 · 0.3% 초과 비율**. 실측 예(28건): 평균 **−0.245%**,
최악 −1.005%, 0.5% 초과 4건. 이 값이 곧 "시장가 청산의 가격"이다.

## 3. 합쳐서 다시 판정

`왕복 실비용 = 요율 fees(%) + 진입 슬리피지 + 청산 슬리피지`. 실측 예: 0.18 + 0.02 + 0.245 ≈ **0.42%**
— 가정 0.21% 의 두 배다. 이 값으로 배리어 격자를 다시 돌리면 +0.162%/건짜리 셀이 0 또는 음수로 내려간다.

규칙:
- 실비용이 가정의 1.5배를 넘으면 **손익비·문턱 결론을 철회**하고, 개선 레버를 모델이 아니라 체결로 옮긴다.
- 가장 큰 항이 청산 슬리피지면 그게 첫 번째 레버다(지정가 청산 + 미체결 시장가 폴백, 폴백 시간 명시).
  단, 지정가 청산은 미체결로 포지션이 묶이는 새 위험을 만든다 — 폴백 없이 켜지 않는다.
- 보고는 항상 **gross / 요율 fees / 슬리피지 / net** 을 한 줄에 같이 쓴다. 하나라도 빠지면 재현 불가.

## 4. 지정가 청산 배선 계약 (슬리피지가 최대 항일 때)

- **엔진의 `execute()` 는 주문을 내는 즉시 저널을 닫는다.** 지정가 청산을 그 위에 얹으면 미체결인데도
  포지션이 청산된 것으로 기록되어, 폴백 시장가가 이중 매도가 되거나 저널이 브로커와 갈라진다.
  지정가 경로는 **저널을 쓰지 않고** 주문만 낸 뒤 브로커 보유수량을 폴링해 확인하고, 수량이 줄었을 때만
  (그 감소분만큼) 계획가로 저널을 닫는다.
- 순서: `order(side=sell, order_type=limit, price=bid1)` → `wait_seconds` 동안 1초 간격으로
  `positions()` 의 보유수량 확인 → 줄었으면 저널 마감·종료 → 안 줄었으면 `cancel(order_no, code, qty)`
  후 **기존 시장가 경로를 그대로 호출**하고 결과에 `fallback="market_after_limit"` 을 남긴다.
- 이미 보유가 0이면 주문을 내지 않고 `status="no_position"` 으로 끝낸다(이중 매도 방지).
- 파라미터는 설정으로: `exit_limit_first`, `exit_limit_wait_seconds=20`, `exit_limit_poll_seconds=1`.
  폴백 시간은 곧 손절 지연 허용치이므로 초 단위로 명시하고 보고에 쓴다.
- 테스트 3케이스 필수: 체결되면 시장가 주문이 **없다**(주문 타입 리스트 == `["limit"]`), 미체결이면
  취소 1회 + 시장가 1회, 보유 0이면 주문 0회.
- 검증은 다음 세션 첫 청산에서: `order_type=limit` 체결률, 폴백 비율, 지정가 청산의 슬리피지(목표 <0.05%).
  단위 테스트가 초록이라는 것은 주문 경로의 증거가 아니다.

## 5. "비싸게 산다"는 주장은 진입가를 시가와 비교해 먼저 측정한다

- 매수 체결가를 당일 시가(`market_data.open_price`)와 짝지어 `(fill/open-1)*100` 분포를 낸다.
  실측 예(14건): 평균 **−1.06%** — 대부분 시가보다 **싸게** 샀다. 추격이 아니라 스프레드가 실체다.
- 처방이 갈린다: 진입이 시가 대비 (+)로 치우치면 신호/타이밍 문제(추격 금지 게이트), (−)인데도 손실이면
  체결 비용 문제(매수도 최우선 매도호가에 걸고 미체결 취소). 측정 없이 게이트부터 넣으면 멀쩡한 진입을 막는다.
- 예외 행은 이름으로 보고한다(예: 시가 +1.2% 추격 후 −2.0%). 평균이 좋아도 개별 추격은 사고다.
