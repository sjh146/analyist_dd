# 방향성 모델 실험 매트릭스 (재사용)

한 설정만 돌려 결론내지 않기 위한 최소 매트릭스. 각 실험은 **시드 0~4 평균±std**로 판정하고,
상위 1~2개만 최근 90거래일 OOS + 수익 시뮬레이션까지 돌린다.

## 1. 하이퍼파라미터 (같은 피처셋·같은 split)

| 축 | 값 | 의도 |
|---|---|---|
| learning_rate | 0.02 / 0.03 / 0.05 | 저학습률 + 얕은 트리가 안정적인 경우가 많다 |
| depth | 3 / 4 / 5(6) | 깊으면 과적합으로 OOS가 먼저 무너진다 |
| n_estimators | 1000 / 1500 / 2000 | early stopping 기준과 함께 본다 |
| scale_pos_weight | 기본 / 1.0 | 상승률 0.46~0.47이면 기본 가중이 편향을 키울 수 있다 |
| 앙상블 가중 | `max(auc-0.5, ε)` / 균등 1/3 | 특정 모델 독주 여부 점검 |
| 시드 | 0~4 | 재현성 측정(필수) |

**주의**: xgboost는 `max_depth`, catboost는 `depth` 키를 쓴다 — 동시 설정하면 충돌한다.
catboost `iterations`는 학습시간이 급증하므로 상한(예: 150)을 두고 돌린다.

## 2. 데이터 파생 변형 (하이퍼보다 효과가 큰 경우가 많다)

| 실험 | 정의 | 기대 |
|---|---|---|
| 위생 필터 | 거래량 0 행 제외 + 직전 거래일과 `시·고·저·종가+거래량` 완전 동일(동결) 행 제외 | 라벨 노이즈 감소 |
| 유동성 유니버스 | 최근 20거래일 평균 거래대금 상위 N(예: 300) | 코드순 선택 편향 제거 |
| 피처셋 비교 | 큐레이션 피처 vs 전체 canonical(0-fill) | 피처 수 문제인지 데이터 문제인지 분리 |
| 시간 가중 | 최근 60거래일 표본 가중 2.0 | regime shift 대응 |
| 피처 생존 필터 | nonzero 비율이 임계 이하인 피처 제외(단 추론 계약 순서는 유지) | 상수 피처 영향 확인 |

## 3. 라벨 변형 (순위 소비자에게 특히 유효)

- **시장상대 라벨**: 그날 전체 종목 수익률 중앙값 대비 상대 방향. 스크리너가 종목 간 순위만 쓰면 이 라벨이 과제와 더 잘 맞는다.
- **호라이즌**: 1일 vs 2~3일. 짧을수록 노이즈가 크다.
- **임계 정의**: "상승"을 `> +0.5%`처럼 정의하면 base rate가 바뀌므로 문턱·상위 N도 함께 재설정한다.

## 4. 측정 절차

1. 피처 패널을 **1회** 빌드해 디스크 캐시로 고정한다(캐시 키에 종목수·기간·마지막 거래일 포함 → 낡은 캐시 재사용 방지). 실험마다 재빌드하면 예산이 녹고 비교 기준도 흔들린다. 종목-일 쌍당 수십 ms이므로 200종목×120일이면 20~30분이다.
2. 각 실험: 학습 → 시드별 AUC → 결과를 `results.jsonl`에 한 줄씩 append(`exp, params, seed_aucs, mean, std, oos, ts`).
3. 상위 후보만 OOS 패널 AUC 측정(후보·현 라이브 모델 같은 프로토콜).
4. 최종 후보는 수익 시뮬레이션까지.
5. **창 민감도**: 같은 설정을 test 창만 바꿔 2~3개 재평가해 변동 폭을 보고한다(과거 "최고값"이 창 선택의 산물인지 판정).

## 5. 자율 루프로 돌릴 때

- 한 번에 실험 1개(병렬 금지). 스레드 제한(예: `OMP_NUM_THREADS=2`)을 걸어 다른 작업과 CPU를 다투지 않게 한다.
- 하트비트 파일(2분 주기) + 결과 jsonl + 실험별 로그를 남겨 밖에서 진행률을 읽을 수 있게 한다.
- **마감 시각을 코드에 박는다**: "이 시각 이후 새 실험 금지 / 이 시각까지 최종 리포트 + done 플래그".
- 실패한 실험은 건너뛰고 사유를 로그에 남긴다(전체 루프를 죽이지 않는다).
- 조기 종료 조건(게이트 통과)을 두고, 통과 시 후보 저장 → OOS → 승격(게이트·백업) → 리포트 순으로 끝낸다.
