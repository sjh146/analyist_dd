1. **AUC 1위였던 h1 은 기대값 −0.145%** — AUC 개선이 돈으로 이어지지 않았다.
   지평 실험의 교훈은 "라벨을 짧게 하면 분류는 쉬워진다"까지이고, 매매 우위는 아니다.
2. **h2 가 사전 기준을 문자상 통과**했지만 **t=0.72** 로 0과 구분되지 않는다.
   표준편차 28.2%(건당!) · 최대낙폭 −437% → 노이즈가 기대값을 압도한다.
   **이 결과로 승격하지 않는다.** 추가 요구: t ≥ 2(=표본 4배 이상) 또는 워크포워드 밖 홀드아웃 재현.
3. h3·h5 는 유의하게 음(−)이다. 즉 현재 모델·유니버스·비용 조합에서 **5일 보유는 확실히 손해**.
4. 61bp 비용이 기대값과 같은 자릿수다. 비용을 30bp로 낮춰도 h2 는 t≈1.5 수준으로 여전히 약하다.
