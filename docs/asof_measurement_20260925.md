# as-of 재무 누수 제거 후 실질 상한 재측정 (2026-09-25)

## 무엇을 바꿨나
`company_features.get_financial_features` 가 `date` 를 받지 않아 **항상 최신 재무 스냅샷**을
썼다(2025-08 행에 2026-06 보고서 → 최대 10개월 룩어헤드). as-of 필터(사업보고서 90일 /
분기·반기 45일 공시 지연)를 추가하고, 기존 패널의 재무 11개 컬럼만 재계산했다
(`scripts/patch_panel_asof.py`) — 전체 재빌드(85분, 컨테이너 재시작에 소실) 대신.

교체 증명: **종목당 유니크값 중앙값 1 → 3** (net_income, operating_profit, revenue,
revenue_growth_yoy, op_margin_change_yoy, op_margin, net_margin, debt_ratio),
pbr_current/roe/per_current 1 → 2. 변경 셀 140,339개.

## 결론
1. **재무 누수를 제거해도 성능은 변하지 않았다** (최대 델타 +0.0005, 폴드 std ±0.03 대비 노이즈).
   → 그 누수는 AUC 를 부풀리고 있지 않았다. 0.6 미달의 원인은 누수가 아니다.
2. **실질 로버스트 상한 ≈ 0.54 확정** (4개 구성이 0.5326~0.5400 에 수렴, 통계적 우월성 없음).
3. 주목: **종목상수 피처만으로 0.5329** — 전체(0.5385)에 근접한다. 이는 walk-forward AUC 의
   상당 부분이 "종목 식별"에서 나온다는 뜻이다(종목별 기저 수익률 차이). 과거에 이 피처군을
   룩어헤드로 의심했으나, as-of 로 바로잡아도 성능이 그대로이므로 **정보는 진짜지만 시간가변이
   아니다** — 즉 이 데이터셋에서 예측 가능한 것은 "그 종목이 오를 성향"이지 "그 날 오른다"가 아니다.
4. rank 횡단면 변환의 해로움(−0.028)은 as-of 수정 후 사라졌다(0.5326). 다만 시간가변 단독보다
   여전히 낮으므로 rank 가 이득이라는 결론은 아니다(과거 철회 유지).
