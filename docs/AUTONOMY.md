# 자율 개선 루프 (analyist_dd) — 목표·봉투·게이트·감시

이 문서는 "analyist_dd 가 사람 개입 없이 돈을 향해 스스로 개선되게" 만드는 구조를 정의한다.
사람이 남기는 것은 **위험 봉투 설정 + Creon 로그인**뿐이고, 그 안의 결정은 기계가 한다.

## 0. 원칙 (실측에서 나온 것)

1. **목표는 돈이지 대리지표가 아니다.** 실측(2026-10-02, 8모델 4축): 단일분할 val AUC ↔ 다중폴드
   OOS AUC 순위 상관 **−0.81**(거의 반대), AUC ↔ 순기대 상관 없음(+0.10/−0.24). → 승격 기준은
   **체결 가능 OOS 순기대(%p/세션)** 이다.
2. **체결 가능성 먼저.** 원시 백테스트는 상한가(중앙 +29.9%) 같은 **살 수 없는 종목**이 이익을
   만든다(87세션 실측: +5.23% → 필터 후 −0.67%). 순기대는 체결성 필터·수수료 왕복 0.21%p 반영.
3. **기준 미달이면 무거래가 정답.** 어떤 모델도 양(+) 기대가 아니면 시스템은 사지 않는다.
4. **무력화·실패는 숨기지 않는다.** 가드 fail-open, 빌더 미배선, 낡은 테이블은 이벤트·경보로 남긴다.
5. **되돌릴 수 있어야 자율로 바꿀 수 있다.** 새 정책은 기본값을 바꾸지 않고 게이트/플래그로 배선한다.

## 1. 단일 진실원 (기계가 읽는 목표)

| 파일 | 내용 | 읽는 주체 |
|---|---|---|
| `config/objective.json` | 목표 지표·프로토콜·수용 기준(개선폭·표본·분할표본)·봉투·게이트 정책 | 파이프라인·게이트·계기판·보고 |
| `scripts/objective.py` | 스키마 검증 · **봉투 드리프트**(트레이더 설정과 비교) · `promote-flags` | 파이프라인·운영자 |
| `data/state/objective_state.json` | 오늘의 목표 값·돈·봉투 위반·1순위 손실원·데이터 신선도 | 루프·경보·아침 보고 |
| `docs/MONEY_GOAL.md` | 사람용 목표·레버·근거 등급 | 사람·에이전트 |

봉투 값의 **소스 오브 트루스는 트레이더 설정**이고 objective.json 은 사본이다 —
`python3 scripts/objective.py envelope-drift` 로 어긋남을 잡는다(현재 일치 확인).

## 2. 매일 도는 루프

```
23:30 money_state_tick (no_agent)
  ├─ money_scoreboard.py     실현손익·자본사용·게이트 기회비용·1순위 손실원
  └─ objective_state.py      목표 값·봉투 위반·신선도 → data/state/objective_state.json
                              (봉투 위반 시 Discord, 같은 경보 반복은 침묵)

20:00 full_pipeline_dd.sh (평일)
  ├─ 후보 학습 → 라이브 스코어 게이트 → **돈 증거 생성**(다중폴드 AUC + 순기대/분할표본)
  └─ champion_promote --require-expectancy … (objective.json 의 플래그)
        증거 없음 / 순기대 ≤ 0 / 표본 부족 / 절반 불안정 / 챔피언 대비 개선 부족 → **승격 거부**

야간 역할 틱 (리서처 2h · 엔지니어 매시 · 리뷰보드·다이제스트)
  가설 등록 → 실험 → 원장 기록(가설·프로토콜·결과·결정)

위임 오케스트레이션 (필요할 때)
  worktree 격리 → 사전등록 프로토콜 → `scripts/verify_agent_worktree.sh` 기계 검증 → 통과 시 병합
```

## 4. 지금 배선된 안전장치

- `champion_promote`: ① 라이브 스코어 게이트 토큰(MT116 재발 차단) ② 돈 증거 게이트
  (`--require-expectancy` — 증거·문턱·표본·분할표본·챔피언 대비 개선) ③ 다중폴드 OOS 훅
- `champion_promote`: 증거 파일 = `<모델>/robust_oos.json`
  (`scripts/model_metric_protocol_audit.py --robust-oos-out` 가 생성)
- `money_state_tick`(23:30): 봉투 위반 경보 · `net_guard_alert`(01/19/20/23:05): 수집정책 경보
- `exit_window_tick`(09:15): 청산창(09:00-09:10) 이탈·슬리피지 실측
- `audit_eod`(15:50)·`safety_preopen`(08:25)·`protocol_lock`(15:55): 역할 감사 4종

## 5. 아직 안 된 것 (다음 단계)

1. **자동 롤백**: 승격 후 `rollback.monitor_sessions`(5) 세션 실측이 기준선 대비 나쁘면 원복.
   지금은 사람이 판단한다(수동 롤백 도구는 있음).
2. **개선 큐**: 백로그 우선순위·중복 방지(현재는 오케스트레이터가 손으로 선정).
3. **작업 감시**: 역할 틱 중단("Interrupted by shutdown", 실측 엔지니어 8/29·리서처 5/15) 감지·재배정,
   "작업 나이" 경보.
4. **조용한 열화 탐지**: 테이블 신선도·피처 0화·리더/writer 배선·가드 폴백을 주간 자기감사로.
5. **수수료 계상**: 트레이더 fills exporter 가 fees=0 → 순손익 신뢰도 결손(봉투 경고로 계속 뜬다).

## 6. 사람이 하는 일 (최소)

1. 위험 봉투 값 확정·변경 (현재: 일 3건 · 종목 10% · 총 30% · 일 손실 3% 자동중단)
2. Creon PLUS 로그인 (브리지 not_connected 일 때 — 09:10 청산창 데드라인 경보가 뜬다)
3. 봉투 위반·킬스위치 발동 후 재개 판단
